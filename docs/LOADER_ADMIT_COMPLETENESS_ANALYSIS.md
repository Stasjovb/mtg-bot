# Loader-admit completeness — what fraction of the real 17lands pool
is end-to-end loader-admittable today

## 0. Why this doc exists

`docs/SOT_FLIP_CUTOVER_PLAN.md` §1.1 + blocker B8 flag that the
flip-readiness criterion **C3** ("≥95% of the LOADER-ADMITTED
population is byte-equal") is **unmeasurable as a percentage today**:
`docs/POOL_PARITY.md` measures the *whole-pool* Effect+bridge fraction
(304/475, 64.0%); the bench tier reads `0/0.0%` by tier-precedence
even though the bench is empirically divergence-clean; and the
*loader-admitted fraction of the real deck pool* is no single tracked
number. The flip honestly rests on **C4 ∧ C6** (bench clean at scale
over the admit population + the admit gate is a hard soundness
boundary), NOT a percentage. This doc supplies the missing
verify-first measurement: **what the loader actually admits today,
deck-weighted over the population the bot plays, what gates the rest,
and what the path to whole-pool full-trajectory coverage is.** It is
the B8 / §1.1 prerequisite, and it does NOT mutate any
orchestrator-owned doc (POOL_PARITY / SUBSYSTEM_ROADMAP /
residue_worklist / EOE_PROBE_READINESS_AUDIT) — it cross-references
them.

## 1. The single chokepoint (verify-first)

The loader admits a card iff it passes **exactly one disjunction** of
five predicates, at the single chokepoint
`trajectory._filter_deck_to_bridge_supported`
(`src/mtg_bot/parity/trajectory.py:4529-4566`), called by
`production_deck_to_deckspec` (`:4124`) — the production deck path
every bench / real-deck trajectory test drives. The disjunction
(`:4550-4561`, verbatim order):

```
_printing_is_bridge_basic_land            (:3795)
_printing_is_bridge_nonbasic_mana_land    (:3827)
_printing_is_bridge_pure_warp_creature    (:3375)
_printing_is_bridge_simple_creature       (:3273)
_printing_is_bridge_simple_spell          (:3702/3721)
```

A name that resolves in the active CardSource but passes NONE of the
five is **silently dropped** from the deck (`:4548-4562` — the
`continue`). This is the loader's admit gate and, per
`SOT_FLIP_CUTOVER_PLAN` C6, the intended flip soundness boundary.

## 3. The load-bearing number: deck-weighted admit over the real
17lands pool

Measured live at `c1815ebf` over **all 129,996** real 17lands deck
records (`data/17lands/eoe_decks.json.gz`; each record's `cards` list
is the full deck):

| Metric | Value |
|---|---:|
| Mean admitted card-slot fraction (full deck incl. basics) | **50.75%** |
| Mean admitted **non-land** card-slot fraction | **17.31%** |
| Decks 100%-admitted (every slot bridge-supported) | **0 / 129,996 (0.000%)** |

**The honest read:**

- A *typical real deck has only ~51% of its card slots
  loader-admittable* — and that figure is inflated by basic lands
  (the ~17 lands of a 40-card limited deck almost all pass
  `basic_land`). **Stripping basic lands, only ~17% of the
  spell/creature slots a real deck actually plays are admitted.**
- **Zero of 129,996 real decks are fully loader-admittable.** Every
  real deck, when loaded through `production_deck_to_deckspec`, has
  ≥1 card silently dropped and is then **padded with Forests to
  `pad_to_size`** (`trajectory.py:4213-4221`). The bench therefore
  does NOT play real decks — it plays the *admitted residue of real
  decks, basic-land-padded*. This is the precise, previously-unstated
  meaning of "scoped to the loader-admitted subset" in the
  `POOL_PARITY` caveat / `HANDOFF` §6a.

This is the verify-first sharpening C3/§1.1 asked for: **C3 as
"≥95% of the loader-admitted population" is technically satisfiable
(the bench IS divergence-clean over what's admitted — `HANDOFF` §6a
round-68/71), but the loader-admitted population is itself ~17% of
real non-land deck content and 0% of whole decks.** The flip is sound
under C4 ∧ C6 (clean over the admit set + the admit gate fences out
the rest), but the post-flip bot plays a **heavily reduced,
basic-land-padded** card universe until admit coverage grows. This
must be stated, not hidden behind "64% byte-equal" (which is the
whole-pool *Effect+bridge* metric, a different and more optimistic
denominator than deck-weighted *end-to-end loader-admit*).

> **Honest scope of the measurement.** "Admitted card-slot fraction"
> counts how many of a deck's listed card slots pass the live admit
> disjunction; it does NOT re-run a full game per deck (that is the
> bench's job, already clean at the round-71 scale). It is the
> *upstream* gate metric — what reaches the engine at all — which is
> exactly the B8 quantity §1.1 said was missing. A deck-frequency-
> weighted variant (weight each deck by its 17lands play frequency)
> would refine the mean; the record-level mean over all 129,996 is
> the honest first-order number and is what this doc commits.

## 5. The path to whole-pool full-trajectory coverage

Whole-pool full-game-trajectory parity (the `POOL_PARITY` caveat's
verbatim "campaign's open frontier") requires the deck-weighted admit
fraction → ~100% AND the bench staying divergence-clean as each new
admit lands. The mechanism is already defined and owned elsewhere;
this doc only indexes it:

1. **Each Effect+bridge close drains the per-card tail** and, for
   single-target instants/sorceries, **auto-joins the spell-card-bridge
   admit set** (the guardrail queries the LIVE covered set — no
   hardcoded list; `_printing_is_bridge_simple_spell` §2 teeth). Owner:
   the Tier-A mini-specs + `SPELL_CARD_BRIDGE_PHASE1_DESIGN`
   (orchestrator sequencing in `SUBSYSTEM_ROADMAP`).
2. **Substrate slices widen the disjuncts**: warp Phase 2 (Timeline
   Culler, +8,986 decks — IN FLIGHT), Tier-C target-seating (2 cards /
   18,855), spell-card-bridge Phase 2 (Diplomatic Relations 2-slot,
   29,818). Owner: the respective design docs +
   `SUBSYSTEM_ROADMAP`/`HANDOFF` §3 queue.
3. **Some shapes are accepted permanent-residue** (Sothera-class
   exile-link composites, Aura-struck, the static-rule-text
   unclassified pair) — they stay loader-DECLINED and the admit gate
   fences them out (`SOT_FLIP_CUTOVER_PLAN` C5/C6). Whole-pool admit
   → 100% is therefore an *asymptote the residue caps below 100%*;
   the honest target is "admit coverage of the real deck-weighted
   distribution → high, residue accepted-with-rationale", NOT literal
   100%.

**Consequence for the flip plan (feeds back into
`SOT_FLIP_CUTOVER_PLAN`):** C3's percentage gate should be restated
as a **deck-weighted-admit trajectory**, not a static bar — the flip
is defensible at the *current* ~17% non-land admit IF C4 (bench clean
over that admit set) ∧ C6 (hard admit boundary) hold AND the reduced
post-flip card universe is an explicitly accepted staged-flip
consequence (it is, per `SOT_FLIP_CUTOVER_PLAN` §7 open question 3).
This doc supplies the number that makes that acceptance honest:
**the staged flip ships a bot that, day-1, plays ~51% of real
deck-slots (≈17% of non-land slots), Forest-padded, with the admit
gate as the soundness fence; admit coverage then grows monotonically
as the campaign's existing Rust sequencing lands.** No criterion in
`SOT_FLIP_CUTOVER_PLAN` is invalidated; C3 is now *measured* (was
unmeasurable) and honestly downgraded to a trajectory.

## 6. Regenerating

```
PYTHONPATH=src ../../mtg-bot/.venv-py313/Scripts/python.exe - <<'PY'
from mtg_bot.cards.source import get_active_source
from mtg_bot.parity import trajectory as T
import gzip, io, json, statistics
P = get_active_source().get_printings()
def admit(n):
    pr = P.get(n)
    return pr is not None and (
        T._printing_is_bridge_basic_land(pr)
        or T._printing_is_bridge_nonbasic_mana_land(pr)
        or T._printing_is_bridge_pure_warp_creature(pr)
        or T._printing_is_bridge_simple_creature(pr)
        or T._printing_is_bridge_simple_spell(pr))
recs = json.load(io.TextIOWrapper(
    gzip.open('data/17lands/eoe_decks.json.gz', 'rb'), encoding='utf-8'))
fr = [sum(map(admit, r['cards'])) / len(r['cards']) for r in recs]
print(len(P), 'printings;', sum(map(admit, P)), 'admitted')
print('mean deck-slot admit %.2f%%' % (statistics.mean(fr) * 100))
PY
```
