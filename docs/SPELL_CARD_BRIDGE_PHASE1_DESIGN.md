```python

    # single-target Instant/Sorcery (EoE Tier-A — Radiant Strike,
    # Seedship Impact, Orbital Plunge, Depressurize, Focus Fire,

    # rejects modal / X / kicker / warp / additional-cost-choice /
    # multi-slot / permanent-spell shapes (later phases / other
    # substrates) so only the lever-correct dict reaches this field.
    spell_effect: Optional[dict] = None
```

Also update the `cross_engine.py:129` doc comment from `# "Land" or
"Creature"` to `# "Land" | "Creature" | "Instant" | "Sorcery"` (the
two-card-kinds class docstring at `cross_engine.py:117-119` is

**Design note (verified against the live `triggered_abilities` /
warp codecs):** `triggered_abilities: tuple[dict, ...]`
(`cross_engine.py:135`) + the warp `(generic, colored)` scalars
(`cross_engine.py:234-236`) both prove the "one frozen-hashable
payload, schema = Rust `parse_*`, bridged by the matching

requirement surfaces, the same `tuple(sorted(...))`-of-items trick the

a `CardDef` with a `spell_effect`, so a plain `Optional[dict]` matches
the `triggered_abilities` precedent and is correct for Phase 1.

The `is_noncreature_spell` predicate is a registry lookup keyed off

creature, fall through to `cast_creature`. This keeps the action arm a
thin dispatcher (the landed warp pattern) and the type authority in
the primitive (the landed `cast_creature`/`cast_creature_warp`
pattern). Pin both routes (§5 pins 1–2).
