### 1.2 Verify-first DROP — Close Encounter is subsystem-entangled, NOT clean Tier-A

`CloseEncounterEffect.resolve` (`effects/bespoke.py:1064`) reads
**`state.resolving_additional_cost_choice_id`** — Close Encounter's

(additional-cost-choice + warp_cost co-gated) — reported here for the
orchestrator fold; it is NOT a single-round clean close.** The triage
doc's §4 row 7 should be re-tagged (report-only; not edited here).

This is the verify-first lesson re-applied: the triage's one-line
"chosen-source-power fight; additional-cost choice" *named* the
entanglement but ranked it inside Tier-A; reading the live `resolve`
