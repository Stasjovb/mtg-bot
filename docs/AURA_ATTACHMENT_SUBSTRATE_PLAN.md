### The hard distinction from the round-39 Ward / round-59 sub-shape-A precedents

Round-59 admitted the 5 shocklands as a *documented deliberate
simplification* because the dropped rider was bit-equal under the
bench's strategy: the parser dropped pay-life on **both** bridge sides
(symmetric drop → still bit-equal), AND `attack_all` never makes the
pay-life decision. Round-39 Ward was the same.

**Aura attachment does NOT have that property — and the asymmetry is
total, not partial:**

- It is not "one rider the parser flattens on both sides." It is the
  *entire object identity*: Python materializes an attached Aura that
  modifies its host (P/T, control, abilities, triggers reading
  `attached_to`); Rust materializes a free-floating enchantment with
  no host and no effect. There is no symmetric-drop bit-equality —
  the two engines model **different objects** the instant the Aura
  resolves.
- The divergence fires on a path the bench drives unconditionally:
  playing the Aura spell. The post-resolution battlefield fingerprint
  (the attached-to linkage, the host's effective P/T / controller /
  abilities, the continuous-effect registry) mismatches immediately —
  Python's host is +2/+2 / controlled / ability-stripped while Rust's
  is untouched and the Aura is host-less.
- For the residue cards it is worse still: Meltstrider's
  `EnchantedCreatureFightsTargetEffect` and Pain for All's ETB +
  damage-echo are bespoke Python Effect classes with **no Rust
  variant and no bridge arm at all** (`cross_engine.py:1166-1176`
  explicitly states the bridge does NOT route the Aura-shape Fight;
  the residue worklist marks both `genuinely_missing`). Tractor Beam's
  bare `TapEnchantedPermanent` ETB Effect *is* shipped+bridged, but it
  reads `source.attached_to` — which Rust never sets for an Aura — so
  even the shipped Effect silently fizzles on the Rust side (residue
  worklist: `blocked_non_effect`, "Aura control-swap + don't-untap
  composition subsystem").

There is no `attack_all`-conditional escape hatch and no
symmetric-drop bit-equality anywhere in the Aura family. Admitting any
Aura by widening the loader gate ships a **guaranteed inter-engine
divergence on the resolution turn**, far larger in blast radius than
cost-reduction (which only perturbed the mana pool).
