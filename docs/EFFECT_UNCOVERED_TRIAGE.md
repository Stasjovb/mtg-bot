## 3. Tier B — the recurring staleness does NOT apply here (honest null result)

Every prior verify-first round (r51 Monoist, r53 Mightform, r54
Famished, r57 Faller's, r60 Perigee) found ≥1 card mis-attributed —
an Effect shipped under a real Rust variant name the plan-invented
label never lexically resolved (the Pulsar mechanism). The premise
anticipated this round would too. **It does not, and that is itself
the finding:**

- The staleness mechanism is *residue-worklist-vs-live-enum* drift. By
  construction, a card whose Effect-half shipped under a name **leaves
  the Effect-uncovered bucket** (its emitted classes become a subset
  of `covered_python_class_set()`), so it is no longer one of the 115.
  The bucket is *defined* as "emits ≥1 class with no covered Rust
  counterpart" — a mis-attributed-but-actually-shipped card cannot
  remain in it. The residue closures (r51..60) already drained that
  drift OUT of this bucket.
- Verify-first spot-checks of the highest-deck Tier-A bespoke classes
  against the **live** Rust `Effect` enum (112 variants at HEAD
  `e6f95002`) by name-proximity confirm genuine absence, not staleness:
  - `ThreatenTargetCreatureUEOT` (Vengeful Possession) — **no
    `Threaten*` Rust variant exists at all**.
  - `PreventAllCombatDamageThisTurn` (Darkness) — **no `Prevent*` Rust
    variant exists at all**.
  - `ExileAllCreaturesAndSpacecraft` (Beyond the Quiet) — `ExileTarget`
    / `ExileEachOpponentsGraveyard` exist; **no board-wide
    creature+Spacecraft exile** variant.
  - `DestroyTargetArtifactOrTappedCreature` (Radiant Strike),
    `DestroyTargetArtifactEnchantmentOrFlyingCreature` (Shattered
    Wings) — Rust has `DestroyTarget` (generic untyped),
    `DestroyTargetArtifact`, `DestroyTargetNoncreaturePermanent`,
    `DestroyTargetNonlandPermanent`; **none carries the
    "artifact-OR-tapped-creature" / "artifact-OR-enchantment-OR-flyer"
    composite target filter** these cards need. The generic
    `DestroyTarget` is NOT a bridge-correct substitute (it would
    silently widen the legal-target set — a §2 mistranslation).

So **Tier B = 0** is a true verify-first null, not an unaudited gap.
**Forward note for the orchestrator fold:** no residue/roadmap
Tier-B reconciliation is needed this round (unlike r54/r57/r60).
The structural reason is documented above so a future round does not
re-litigate "did we miss a staleness?" — the answer is: the bucket's
definition makes Tier-B-within-it impossible; staleness lives in the

### Per-card genuine-probe sketches — top 5 (the round-64..68 lane)

The detailed sketches follow the `RESIDUE_CARD_PLANS.md` #1-3 rigor.

#### Round-64 pick — Diplomatic Relations (29,818 decks)

- **Oracle:** `[Instant] {2}{G}` — "Target creature you control gets
  +1/+0 and gains vigilance until end of turn. It deals damage equal
  to its power to target creature an opponent controls."
- **Why #1:** highest-deck Tier-A card; pure composition of shapes
  both engines already model — UEOT P/T+keyword grant (the
  `PumpTargetArtifactOrCreatureUntilEOT` family, live) + a
  source-power fight-half. Two independent "target" clauses (CR 608.2c
  partial-resolution applies — established convention from Monoist
  r51). No Aura, no cast-cost, no subsystem.
- **Effect shape:** new bespoke `Effect::DiplomaticRelationsEffect`
  (composite; or `Sequence(PumpTargetCreatureUEOT{+1/+0,vigilance},
  DealDamageEqualToSourcePowerToTarget)` if both halves are
  individually bridge-correct — verify the vigilance-grant arm is in
  the covered set first; the **source** of the damage is the pumped
  creature, so its post-pump power must be read at resolve).
- **Genuine-probe sketch:** load the real Diplomatic Relations
  printing; controller has a creature C, opponent has a creature O;
  resolve; assert byte-equal that C is +1/+0 with vigilance UEOT and O
  took (C.power) damage, on both engines. Real EoE consumer (29,818
  decks) — genuine, not synthetic.
- **Est:** 1 round. **§2 risk:** the damage source-power must be read
  *after* the +1/+0 applies (pin it — a pre-pump read silently
  diverges); the deterministic-first-target convention covers the
  no-callback target picks.

#### Round-65 pick — Orbital Plunge (28,629 decks) ★ Lander-rider

- **Oracle:** `[Sorcery] {3}{R}` — "Orbital Plunge deals 6 damage to
  target creature. If excess damage was dealt this way, create a
  Lander token."
- **Why:** the **Lander-rider family lead** — `CreateToken` and
  `Sequence` and `DealDamageAnyTarget` are all live+bridged Rust
  variants; the *only* new shape is the excess-damage→Lander
  conditional rider (the round-56 N1
  `ExileEachOpponentsGraveyard`+Lander precedent: the Lander
  token-creation half is solved; this is the damage-excess detector
  rider). Cheapest genuine close after #1.
- **Effect shape:** `Effect::DealDamageToTargetCreatureWithExcessLanderRider
  { amount: 6 }` — deal 6, compute `excess = max(0, 6 -
  lethal_needed(target))`, if `excess > 0` create a Lander token for
  the controller (reuse the live Lander `CreateToken` leaf — file-iso
  re-derive, do not cross-import).
- **Genuine-probe sketch:** real printing; opponent 2/2 creature →
  6 dmg, excess=4>0 → 1 Lander created; assert byte-equal token +
  state. Negative pin: target with toughness ≥6 → excess=0 → no
  Lander.
- **Est:** 1 round. **§2 risk:** "excess damage" = damage beyond
  lethal (CR 120.10) — pin the lethal computation matches Python's
  `damaged_this_turn`/lethal helper exactly (the Faller's r57
  damaged-this-turn-ledger lesson: keep it to the at-resolve excess,
  not a general damaged-this-turn ledger).

#### Round-66 pick — Depressurize (28,346 decks)

- **Oracle:** `[Instant] {1}{B}` — "Target creature gets −3/−0 until
  end of turn. Then if that creature's power is 0 or less, destroy
  it."
- **Why:** self-contained debuff-then-conditional-destroy; UEOT P/T
  modifier (live family) + a power-threshold conditional destroy. No
  subsystem. Recurring shape (a "soft removal" archetype).
- **Effect shape:** `Effect::DepressurizeEffect` — apply −3/−0 UEOT to
  the single target, then `if effective_power(target) <= 0 { destroy
  }`. The conditional reads **effective** post-debuff power (pin it).
- **Genuine-probe sketch:** real printing; target a 2/2 → becomes
  −1/2 → power ≤0 → destroyed; assert byte-equal. Negative pin:
  target a 5/5 → 2/5, survives.
- **Est:** 1 round. **§2 risk:** effective-power read post-UEOT-mod
  (same class as the Cut Propulsion / Mightform double-power read).

#### Round-67 pick — Focus Fire (23,211 decks)

- **Oracle:** `[Instant] {W}` — "Focus Fire deals X damage to target
  attacking or blocking creature, where X is 2 plus the number of
  creatures and/or Spacecraft you control."
- **Why:** an **X-from-count on a NEW denominator** (creatures +
  Spacecraft you control, +2 base) — the exact round-32..49
  X-from-count substrate family the campaign proved mechanical; only
  the denominator (creatures+Spacecraft) and the +2 base offset and
  the attacking/blocking target filter are new.
- **Effect shape:** `Effect::FocusFireEffect { base: 2 }` — `x = 2 +
  count(creatures ∪ Spacecraft controller controls)`; deal `x` to the
  single attacking-or-blocking target. Unit-ish (base is the only
  payload).
- **Genuine-probe sketch:** real printing; controller controls 3
  creatures + 1 Spacecraft → X = 2+4 = 6; target an attacking 5/5 →
  6 dmg → dies; assert byte-equal.
- **Est:** 1 round. **§2 risk:** the count is `creatures and/or
  Spacecraft` — a creature that is also a Spacecraft counts ONCE
  (set-union, not sum); pin it (the only subtle divergence).

#### Round-68 pick — Biosynthic Burst (22,799 decks)

- **Oracle:** `[Instant] {1}{G}` — "Put a +1/+1 counter on target
  creature you control. It gains reach, trample, and indestructible
  until end of turn. Untap it."
- **Why:** counter + multi-keyword-UEOT-grant + untap, single target,
  no subsystem. The +1/+1-counter and untap primitives are live; the
  composite (counter then grant-3-keywords-UEOT then untap, atomically
  on one target) is the bespoke arm.
- **Effect shape:** `Effect::BiosynthicBurstEffect` — on the single
  target you control: add a +1/+1 counter; grant
  {reach,trample,indestructible} UEOT; untap. (Verify whether the
  existing keyword-grant arm can carry a 3-keyword set bridge-correct;
  if so this may compose from covered arms — check before assuming
  bespoke.)
- **Genuine-probe sketch:** real printing; target own tapped 2/2 →
  3/3 (counter), tapped→untapped, has reach/trample/indestructible
  UEOT; assert byte-equal incl. the UEOT keyword expiry at cleanup.
- **Est:** 1 round. **§2 risk:** indestructible UEOT must interact
  correctly with SBA at end of turn (the round-39 SBA-on-0/0 class) —
  pin the cleanup.
