- **157 (33.1%)** are BLOCKED, broken out below.

> **CAVEAT — what this measures vs. what it does NOT.** This is **Effect+bridge-level byte-equality evidence**, NOT full-game-trajectory parity. The PROBED tier asserts byte-equality on a *controlled* cross-engine state (a real EoE printing driven end-to-end), not over a full random multi-turn game. The covered-by-construction tier only proves the card's Effect *primitives* all exist + bridge — it does **not** prove the card plays byte-equal in a real game. The bench tier is the empirical full-trajectory signal but is **capped at ~22-25 turns** (see `docs/bench_trajectory_parity_smoke.md`) and only over the loader-admitted subset. **No tier here claims the whole pool is byte-equal in real full-game trajectories** — that remains out of scope and is the campaign's open frontier.

### Tier definitions

Evaluated in this strict precedence (a card lands in the FIRST tier it qualifies for):

1. **PROBED byte-equal** — a `test_cross_engine_real_eoe_<slug>_parity` function in `tests/test_parity_smoke.py` (slug = the card's printed-name slug, split cards keyed on the left face) asserts byte-equality for THIS card. `*_divergence_pin` functions are excluded (they pin a KNOWN divergence). Strongest evidence.
2. **Effect+bridge covered (not individually probed)** — every distinct Python `Effect` class the card emits (walked with `measure_effect_coverage`'s exact walker) is in that script's covered-class set (live Rust variant + bridge), AND the card is not a residue-worklist BLOCKED entry. A 0-Effect vanilla / keyword-only card qualifies here only if loader-admitted. Covered-by-construction — weaker than a genuine probe.
3. **bridge-admitted & bench-exercised** — the production-deck loader admits the printing (`trajectory._printing_is_bridge_basic_land` or `_printing_is_bridge_simple_creature` — the exact bench admit gate) and the bench runs it 0-divergence at scale. Bounded-depth empirical signal (~22-25 turn cap).
4. **BLOCKED** — not byte-equal-covered today; broken out:
   - **genuinely_missing** — a residue-worklist `genuinely_missing` entry: a TRUE new-Rust-Effect ask (the load-bearing "how far from parity" gap).
   - **blocked_non_effect** — a residue-worklist `blocked_non_effect` entry: Effects shipped, gated by a non-Effect path (unbridged event / declined cost-mechanic / unmodeled subsystem / token-registration substrate).
   - **subsystem-gated / Effect-uncovered** — the long blocked tail: emits an Effect with no covered Rust counterpart, or is loader-rejected by a subsystem gate (Station / Ward / Devour / warp / Aura / Rooms / BECOMES_TAPPED / dynamic-P/T / activated+static abilities / planeswalker / …), and is not itemised in the residue worklist.
